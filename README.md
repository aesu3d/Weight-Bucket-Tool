# Weight Bucket

![Blender](https://img.shields.io/badge/Blender-4.2%2B-orange?logo=blender&logoColor=white)
![License](https://img.shields.io/badge/license-GPL--3.0-blue)

A lightweight Blender addon that brings a "Bucket" tool to Weight Paint mode!! ^-^
Made to quickly fill separate mesh islands with any weight value without having to switch to Edit Mode!

<img width="1000" alt="Animation" src="https://github.com/user-attachments/assets/92f5eaa7-3870-4747-9368-eeecb4bcfa62" />

## Features
- **Instant Island Fill:** Fill whole mesh islands in one go!! No more tabbing into Edit Mode, pressing `L` to select linked vertices, and assigning weights by hand.
- **Easy Weight Control:** Pick and apply exact weight values (from `0.0` to `1.0`) using your brush weight or a custom value in the panel.
- **Clean Workspace:** Located in the **AESU** sidebar tab (`N`) and only shows up in Weight Paint mode to keep your UI nice and tidy!
- **Replace / Add / Subtract modes**
- **Mirror X**, fills a mirrored island too
- **Normalize**
- Works on posed meshes and skips hidden faces!

## Installation
1. Download the latest `.zip` from [Releases](https://github.com/aesu3d/Weight-Bucket-Tool/releases)
2. In Blender: **Edit → Preferences → Get Extensions → ⌄** (top right dropdown) **→ Install from Disk**.

*Tip: You can also just drag and drop the `.zip` file right into Blender's 3D Viewport to install it!!*

Requires Blender 4.2+, works up until the latest ver.

## How to use
1. Select your armature, `Shift`-select your mesh, and switch to **Weight Paint** mode.
2. Press `N` to open the sidebar and click on the **AESU** tab.
3. Pick your target bone / Vertex Group and set the weight you want (you can use your brush weight or set a custom one right in the sidebar!).
4. Hover your cursor over a mesh island and press `Alt + F` to fill it instantly!!
5. Or, toggle **Bucket Mode** to just click and fill as many islands as you want until you press `Esc` or `Right-Click`!
